# 音频实现与可验证边界

## 管线

`原始字节 → FLAC 整数/MP3 浮点解码 → 需要时 libsoxr → Float64 TPT → Float32 → RemoteIO`

FLAC 整数使用 2 的幂缩放，16/24/32 位整数到 Float64 不损失表示精度；到 Float32 时 16/24 位整数可以精确表示，32 位 PCM 会有最终舍入。MP3 请求浮点输出，不经 16 位整数中转；解码器内部精度由 mpg123 的受测构建决定，不声称它是全双精度。MP3 不是无损格式。

`AVAudioSession` 使用 playback + measurement，不请求混音、duck、语音处理。设备不接受 measurement 时明确显示实际模式。会话先请求源采样率，再激活并读取 sampleRate；RemoteIO 在不启动播放的情况下完成初始化/回读协商，采样率稳定后才配置解码器、SRC 和 DSP 并做峰值分析。不能只读初始化前的格式：模拟器已出现初始化前输出率为零、初始化后 48 kHz、会话仍为 44.1 kHz 的情况。若初始化后仍不报告有效输出率，采用会话值并明确标记“硬件端未验证”，不伪造回读成功。App 处理、会话、RemoteIO 客户端/输出端分别显示。正式初始化及恢复播放时校验客户端 Float32 双声道交错格式与 DSP 一致，输出端有效时也必须相同；有效格式变化时停止并重建。偏好请求失败可按实际采样率继续。系统内部未知处理不标记为“已绕过”，RemoteIO 输出端格式也不是对 DAC 物理工作方式的测量。

## EQ

七种二阶滤波器使用梯形积分 TPT 状态变量结构；系数、状态与运算为 double。搁架使用 RBJ 的 Q 版本，峰值使用 A=10^(gain/40)，带通为单位中心增益。不会混入模拟饱和、噪声注入或动态响度处理。

处理与曲线共享同一份设计函数。静态系数与独立 RBJ 实现验证；零增益峰值/搁架跳过运算。单位增益旁路为逐样本拷贝；默认 A/B 旁路保留共同前置增益并明确显示，可关闭“A/B 保持共同前置增益”恢复单位增益。实际 EQ 前置增益可以低于用户界面手动范围，因为安全衰减可能需要额外余量。

调参不直接插值递归分母系数。0.3.0 修改参数时保留当前已生效链路，在后台完整分析并从实际连续链路首曲恢复 SRC/EQ 历史，追上进度后以约 50 ms 线性权重切入。App 不再发送仅两秒预热、极端临时衰减的试听链。内核保留直接控制接口供独立测试，正常界面仅提交经过完整校准的新设计。缓冲帧携带滤波器及旁路修订号，界面区分“准备／目标响应／正在切换”和“已生效”。交叉过渡是时变处理，不声称调参期间完全没有调制边带。

开关 EQ 不重新设计或测峰。湿声链在旁路期间保持状态更新，干声直接使用同一输入、默认保留共同静态增益。切回湿声不会重新初始化高 Q 状态。两侧同增益不等于主观响度匹配，EQ 的频谱变化仍可改变响度。

频率上限为 `min(20000, 0.498 × fs)`，保存值超过上限时明确显示实际频率，曲线采样包含准确的滤波器中心及高 Q 邻域。Q、搁架半增益转折点和二阶滤波器的定义在界面说明。选用的是 RBJ 数字响应：BLT 预扭曲对准中心/转折频率，但接近奈奎斯特频率仍会发生带宽压缩，不等于模拟域固定带宽。固定线性 EQ 不需要用过采样来抑制本来不存在的非线性谐波；本版不增加 EQ 过采样，也不声称自动实现 decramping。陷波含单位圆零点，因此不笼统地把所有类型标成严格最小相位。

极小状态低于 `1e-290`（约 −5800 dBFS）时归零，避免 subnormal 算术开销，不用噪声注入。双声道共享设计参数、独立保存状态，不做交叉混合；动态 EQ、多声道及 M/S 不在本版实现范围。

## 峰值保护

完整分析使用与播放相同的解码、SRC、EQ，另以 libsoxr 8× 插值测量真峰值；0.3.0 同时测量 EQ 和相同用户前置的干声，取较大值保护 A/B 两侧。`safety=min(0,-1-20log10(truePeak))`，实际前置为用户设定+safety；不增加用户未请求的正增益。分析缓存键含文件顺序/SHA-256、规范化滤波器数值、输出率、A/B 分析方式和内核版本，不包含总开关和界面 UUID。缓存通过 SQLite 主键查询，不逐条解码全部历史记录。

内核的 L1 上界仍用于独立验证稳定性和输入/输出峰值界，但 0.3.0 界面不再用它反复压低试听音量。修改参数需等待新校准完成；这段时间播放当前安全链路，未准备好第一套 EQ 时以明确标记的原音旁路播放。

输出监测非有限数值/过载，出现异常即暂停，不用隐藏限幅器掩盖问题。单位增益旁路的超满刻度 MP3 或 SRC 重建峰值仍可能触发保护。0.3.0 分别保存真实过载的峰值/位置与其他解码、网络、状态错误，不再只显示混合的通用“过载”提示；工作线程错误保存在播放器内供主线程读取。

8× 插值仅用于离线峰值测量，不插入实际播放链路。测量位于最终 Float32 舍入前，保留的 1 dB 余量远大于正常 Float32 舍入误差，但不把它当作硬件 THD+N 或所有重建滤波器的保证。EQ/专辑结束不额外追加滤波器尾音，分析也按同一长度处理。

## 线程与无缝

原生解码线程填充固定大小 SPSC 环。RemoteIO 仅复制缓冲到系统提供的输出区，不分配、不加锁、不访问网络或磁盘。缓冲不足填充的是硬件必需的静音帧，播放位置不因此推进，也不伪造丢失音乐。

本地播放不再等待整首/整专辑测峰。已有匹配 EQ 缓存时直接采用，没有时先播放旁路并后台校准，完成后切换。MP3 准确时长在导入曲库时索引并保存，播放打开不重新扫描全部帧。首次 EQ 准备耗时并未消失，长连续专辑或大量滤波器仍需后台处理时间。

同源采样率和声道数的下一首提前打开并预解码，原始 PCM 接入同一个 SRC，保留其相位与历史，并保持 EQ 状态。连续专辑按实际播放顺序整段分析，覆盖交界处余振，共享同一个静态安全增益。不同专辑开启 EQ 时重新分析并重建链路；硬件采样率变化允许短暂停顿，不固定升频。

本地定位在后台从原文件起点重放到目标位置以恢复 SRC 相位和 EQ 状态；原生连续链内定位也包含此前曲目。App 重新选择某曲或定位重建播放器时以该曲作为新的链路起点，并据此重新分析，不能把两种起点混用。长文件/长连续序列、高 Q 和 32 段会增加准备时间，真机耗时与断音压力测试仍待进行。

逐项审计、修复依据和测试边界见 [EQ 与播放链路复核](EQ-AUDIT.md)。0.3.0 对临时试听、启动和旁路行为的调整见 [修复说明](0.3.0-FIXES.md)，取代旧版审计中的临时保守试听流程。
