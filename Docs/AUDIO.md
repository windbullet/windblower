# 音频实现与可验证边界

## 管线

`原始字节 → FLAC 整数/MP3 浮点解码 → 需要时 libsoxr → Float64 TPT → Float32 → RemoteIO`

FLAC 整数使用 2 的幂缩放，16/24/32 位整数到 Float64 不损失表示精度；到 Float32 时 16/24 位整数可以精确表示，32 位 PCM 会有最终舍入。MP3 请求浮点输出，不经 16 位整数中转；解码器内部精度由 mpg123 的受测构建决定，不声称它是全双精度。MP3 不是无损格式。

`AVAudioSession` 使用 playback + measurement，不请求混音、duck、语音处理。设备不接受 measurement 时明确显示 Default。会话先请求源采样率，再激活并读取 sampleRate；解码器和 DSP 以真实输出采样率配置。系统内部未知处理不标记为“已绕过”。

## EQ

七种二阶滤波器使用梯形积分 TPT 状态变量结构；系数、状态与运算为 double。搁架使用 RBJ 的 Q 版本，峰值使用 A=10^(gain/40)，带通为单位中心增益。不会混入模拟饱和、噪声注入或动态响度处理。

处理与曲线共享同一份设计函数。静态系数与独立 RBJ 实现验证；零增益峰值/搁架跳过运算，总旁路为逐样本拷贝。实际 EQ 前置增益可以低于用户界面手动范围，因为安全衰减可能需要额外余量。

调参不直接插值递归分母系数。新链独立分配状态，以最多两秒历史输入预热，再以 50 ms 线性权重交叉过渡；高 Q 的长衰减尾部及大幅参数跳变纳入测试。音频缓冲帧携带配置修订号，界面区分“正在切换”和“已生效”。

## 峰值保护

完整分析使用与播放相同的解码、SRC、EQ，另以 libsoxr 8× 插值测量真峰值。`safety=min(0,-1-20log10(truePeak))`，实际前置为用户设定+safety；不增加用户未请求的正增益。分析缓存键含文件 SHA-256、EQ JSON、输出率和内核版本。

实时编辑用输入样本峰值与每段冲激响应 L1 范数乘积给出上界；L1 包括状态矩阵特征模态的无限尾部界，额外保留过渡余量。它比只按最大频响削减更保守，因此调参期间可能明显降低响度。稳定后回到整首实测静态增益。

输出监测非有限数值/过载，出现异常即暂停，不用隐藏限幅器掩盖问题。EQ 旁路不悄悄改变增益；超过数字满刻度的 MP3 解码峰值会触发保护并提示开启安全 EQ。

## 线程与无缝

原生解码线程填充固定大小 SPSC 环。RemoteIO 仅复制缓冲到系统提供的输出区，不分配、不加锁、不访问网络或磁盘。缓冲不足填充的是硬件必需的静音帧，播放位置不因此推进，也不伪造丢失音乐。

同源采样率和声道数的下一首提前打开并预解码，原始 PCM 接入同一个 SRC，保留其相位与历史，并保持 EQ 状态。连续专辑按实际播放顺序整段分析，覆盖交界处余振，共享同一个静态安全增益。不同专辑开启 EQ 时重新分析并重建链路；硬件采样率变化允许短暂停顿，不固定升频。
