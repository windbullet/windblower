# 0.4.0：EQ 图表、音乐多选、歌单添加和歌词

## EQ 显示

移除频段小圆点、选点按钮和图表拖动手势，图表只显示响应。频率、Q、增益、前置增益都在下方编辑区调整，保留精确数值输入，并提供频率/Q 的对数滑块。

旧图表本身已用对数频率坐标，但外置刻度文字用 HStack 等距排布，与实际坐标不一致。现在刻度、网格、响应共用同一套映射：`x=log10(f/10)/log10(fmax/10)`。每十倍频率等宽、每倍频程等宽，右边界随实际奈奎斯特限制调整；纵轴使用等距 dB。刻度文字在对应坐标绘制，窄屏只减少重叠文字，不改变坐标比例。

没有更换音频内核、滤波器或防削波算法。

## 曲库与歌单

所有歌曲列表提供“多选”，覆盖全部歌曲、收藏、专辑、歌手、文件夹与歌单。支持可见结果全选/取消全选、批量收藏、添加到现有或新建歌单、删除本机歌曲。搜索期间保留已选歌曲，按钮明确显示选择数量。

歌单详情右上角加号打开“从曲库添加”，可搜索和多选现有歌曲，已在歌单中的曲目标记“已添加”，不会重复加入；空歌单也提供该入口。侧栏处于歌单页面时，加号用于新建歌单。

“移出歌单”只移除该歌单关联；“删除”经明确确认后删除本机音频，同时清理其他歌单关联和播放队列。删除过程中先暂存原文件，SQLite 更新在同一事务内完成，失败时恢复原文件；路径检查限制在 App 的 Music 内。

## 歌词

- 读取 FLAC 的 UTF-8 Vorbis 标签及内嵌 LYRICS/UNSYNCEDLYRICS；导入及已有曲库元数据修复不修改原文件。缺少标签时清理文件名里的曲序、末尾平台数字编号，并按目录回退歌手。
- 歌词加载跟随根界面的当前歌曲，不再只依赖打开播放弹层；重复打开播放页不会取消已有搜索。
- 网易、QQ、酷狗和 LRCLIB 独立查询，先有可用结果即显示，继续寻找更高质量时间轴；单个失败候选不丢弃该源的其他结果。
- LRCLIB 精确查询不强制专辑名，查无时再搜索。空歌词不再包装成“暂无歌词”候选。
- 自动选择检查歌名/已知别名、歌手、时长和版本，再优先逐字；手动搜索允许查看不符合旧标签的候选，由用户确认并保存绑定。不同版本和不兼容时长不自动套用。
- 新增“候选歌词与搜索诊断”页面，逐源显示 HTTP/限流/格式失败或没有匹配版本，支持重新自动匹配。手动绑定仍优先保留，本地歌词可离线使用。

## 验证与边界

在用户指定的本机音乐目录抽样 11 首，覆盖日语、中文、英文及 MP3/FLAC：10 首取得匹配在线歌词，另 1 首通过内嵌歌词可用。部分曲目存在罗马音、汉译名和日文原名差异，需要用户手动搜索并绑定；不为凑匹配率自动绑定其他歌手/版本。该抽样不是全部 342 首或所有网络环境的覆盖。

本机探测脚本只读取标签和请求歌词接口，不上传音频，也不把歌词正文写入报告。云端另用原生 URLSession 查询三首已知曲目、运行缓存/匹配/解密测试；界面测试实际操作多选和歌单加号。最终通过情况、安装包和截图以 [验证状态](VALIDATION.md) 为准。
